# Şanlıurfa Halı Yıkama Rehberi

Şanlıurfa'da halı yıkama öncesi kontrol listesi, iklim ve toz koşullarına göre bakım notları ve Eyyübiye, Haliliye, Karaköprü ilçelerine özel kısa bilgi sayfaları.

Bu repo ücretsiz ve bağımsız bir mini-kaynak setidir. Canlı HTML sayfaları GitHub Pages üzerinden yayınlanır:

- Ana sayfa (Şanlıurfa halı yıkama): `https://ahmetalkan.github.io/sanliurfa-hali-yikama-rehberi/`
- Eyyübiye halı yıkama: `https://ahmetalkan.github.io/sanliurfa-hali-yikama-rehberi/eyyubiye-hali-yikama.html`
- Haliliye halı yıkama: `https://ahmetalkan.github.io/sanliurfa-hali-yikama-rehberi/haliliye-hali-yikama.html`
- Karaköprü halı yıkama: `https://ahmetalkan.github.io/sanliurfa-hali-yikama-rehberi/karakopru-hali-yikama.html`

It cites public pages on [mimhaliyikama.com](https://mimhaliyikama.com/) and official reference sources listed at the bottom of each page. Nothing here is a substitute for advice from a qualified professional.

## Files

- `index.html` — Şanlıurfa halı yıkama ana rehber ve teslim öncesi kontrol listesi
- `eyyubiye-hali-yikama.html` — Eyyübiye halı yıkama yerel bakım notları
- `haliliye-hali-yikama.html` — Haliliye halı yıkama apartman ve elyaf bakım rehberi
- `karakopru-hali-yikama.html` — Karaköprü halı yıkama yeni yerleşim ve inşaat tozu rehberi
- `robots.txt`
- `sitemap.xml`
